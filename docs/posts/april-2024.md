### Stars Added ⭐

- Starred [Streamed](/video#live-sports) in Live
  Sports. Fast streams, no ads.

- Starred [Poke](/social-media-tools#youtube-frontends) in
  YouTube Frontends. Nice UI, download support, no ads.

- Starred [Motrix](/file-tools#download-managers) in Download
  Managers. Some people prefer this over Jdownloader / IDM.

- Starred [Openlib](/mobile#android-reading) in
  Android Reading. Anna’s Archive app.

- Starred [Stacher](/social-media-tools#youtube-downloaders) in
  YouTube Downloaders. Modern YT-DL GUI.

- Starred [DeepLX](/text-tools#translators) in Translators.
  Unlimited DeepL.

- Starred [Claude](/ai#online-chatbots) in Online Chatbots.
  Works better than things like Gemini.

- Starred [Soft98](/downloading#software-sites) in
  Software Sites. Big library, single click DDL.

- Starred [JellyPlayer](/video-tools#jellyfin-tools) in Jellyfin
  Tools. Modern Jellyfin client.

- Starred [UniGetUI](/system-tools#package-managers) in Package
  Managers. Nice user interface for Winget.

- Starred [Zipline](/image-tools#screenshot-tools) in Screenshot
  Tools. Self-hosted, feature-rich ShareX server.

- Starred [WSABuilds](/mobile#android-emulators) in
  Android Emulators. Pre-built WSA binaries that will continue to be
  [updated](https://ibb.co/R4hssDc).

- Starred [SmartImage](/image-tools#reverse-image-search) in
  Reverse Image Search. Multi-site reverse image search tool.
